Lo que el cliente elige al finalizar la compra.
  1. Entrega: poné cuánto cobrás. Vacío = "a coordinar", 0 = gratis.
  2. Gratis desde regala el envío a partir de un monto: ayuda a vender más. Para todo el país, marcá "depende de la provincia".
  3. Pago: podés dar un descuento, ej: 10% por transferencia.

Formas de entrega

Poné cuánto cobrás a cada provincia. Las que dejes vacías quedan "a coordinar". El "Gratis desde" de arriba vale igual.

Formas de pago

El descuento se aplica a los productos, no al envío.
